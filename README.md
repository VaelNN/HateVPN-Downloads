# HateVPN

1. Скачайте и установите приложение из [релиза](https://github.com/VaelNN/HateVPN-Downloads/releases/latest).
2. Скачайте [файл с приглашениями](https://github.com/VaelNN/HateVPN-Downloads/releases/download/v1.1.2/HateVPN-15-invites.html), откройте его и нажмите **«Скопировать ссылку»** у одного приглашения.
3. В HateVPN откройте **Подключения → Доступ от друга**, вставьте ссылку и нажмите **«Добавить подключение»**. Затем включите VPN.

Каждое приглашение активируется один раз. Если ссылка уже использована, выберите другую.
